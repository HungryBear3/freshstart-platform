# FreshStart-IL v2 — Brand/Logo Handoff Checklist

Purpose: enumerate the minimum assets and design decisions Alexy needs to provide before the v2 design can be promoted to production. No new brand is invented in this doc — these are placeholders that need real values.

## 1. Logo SVG (single asset, single file)

Current placeholder lives at `app/v2/_components/Logo.tsx:7`. Both the header and the footer call through the same component, so the production swap is one file. The placeholder is:

- a 32×32 oval mark filled with `--fs-grad` (purple→blue) with a white check inside
- a wordmark reading `Fresh**Start**IL`

What's needed from Alexy:

- [ ] Final logo SVG (inline-ready or `<img>`-ready). Preferably inline so it inherits `currentColor` where appropriate.
- [ ] Light-background and dark-background variants if the design needs different fills (the v2 surface is dark today).
- [ ] Favicon / app icon set (PNG fallback) — currently generated by `scripts/generate-favicon.mjs` against an older brand mark.
- [ ] OG/Twitter card image (1200×630) if it differs from the favicon.

Swap path:
1. Replace the inline SVG body in `app/v2/_components/Logo.tsx`.
2. If header and footer want different sizes, expose a `size` prop on the component instead of forking.
3. Regenerate favicons (`node scripts/generate-favicon.mjs`) if the mark changed.
